====================================================
        NAPS2 WebScan LocalService
         Scanner TWAIN para HTTP/eSCL
====================================================

Este pacote expoe scanners TWAIN via HTTP, permitindo digitalizar
pelo navegador ou por clientes eSCL.


INSTALACAO RAPIDA (WINDOWS)
===========================

1. Execute "instalador.bat" como Administrador
2. Digite 1 e pressione ENTER (instalar servico)
3. Digite 3 e pressione ENTER (iniciar servico)

Para o passo a passo completo, veja README_INSTALACAO.txt.


VERIFICAR INSTALACAO
=====================

Abra no navegador:
  http://127.0.0.1:5000/api/scanners

Deve retornar uma lista JSON com os scanners detectados.


COMANDOS DO INSTALADOR
======================

instalador.bat (menu):
  1. Instalar como servico
  2. Desinstalar servico
  3. Iniciar servico
  4. Parar servico
  5. Ver scanners disponiveis
  6. Abrir API no navegador
  0. Sair


API REST (127.0.0.1:5000)
=========================

  GET  /api/scanners            Lista os scanners
  GET  /api/scanners/{id}       Dados de um scanner
  GET  /api/scanners/count      Total de scanners
  POST /api/scanners/refresh    Atualiza a lista de scanners


PROTOCOLO eSCL
==============

Cada scanner recebe sua porta eSCL, a partir de 9880:
  http://127.0.0.1:9880/eSCL/ScannerCapabilities

Use essas URLs para digitalizar via eSCL (compativel com AirPrint).


REQUISITOS
==========

- Windows 10/11 ou Windows Server 2016+
- .NET 8.0 Runtime (ou pacote self-contained)
- Drivers TWAIN dos scanners instalados
- Permissao de Administrador (para instalar o servico)


DESINSTALAR
===========

1. Execute instalador.bat como Administrador
2. Opcao 2 (desinstalar servico)
3. Apague a pasta
